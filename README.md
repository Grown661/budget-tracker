# Budget Tracker

**Live-Demo:** https://grown661.github.io/budget-tracker/

Wer nicht weiss, wohin das Geld geht, kann nicht sparen – dieser Tracker erfasst Einnahmen und Ausgaben pro Monat und zeigt sofort Saldo und Kategorien-Verteilung.

## Features

- Einnahmen und Ausgaben mit Kategorie und Datum erfassen
- Monatsauswahl mit Saldo, Einnahmen- und Ausgaben-Summe
- Balken-Chart der Ausgaben je Kategorie (selbst gezeichnet mit Canvas, keine Chart-Lib)
- Kategorie-Autovervollständigung aus bisherigen Einträgen
- CSV-Import und -Export (Format: `Datum,Kategorie,Betrag` – Betrag signiert)
- Daten bleiben lokal im Browser (localStorage)

## Stack

- HTML, CSS, Vanilla JavaScript, Canvas 2D
- Keine Abhängigkeiten, keine Build-Kette

## Setup & Start

`index.html` im Browser öffnen – fertig.
